# Signal Arena — Спецификация арта

> **Статус:** арт-ассеты **удалены**. Вместо AI-заглушек используется
> procedural fallback — сплошные тёмно-серые квадраты из палитры (`PALETTE.bgN`).
> Всё игровое содержимое — в идеях (`docs/specs/CONCEPT_IDEAS.md`).

---

## 1. Принцип замещения

AI-сгенерированные ассеты оказались низкого качества. Пока используется
**procedural заглушка**: сплошной тёмно-серый квадрат (`0x0a0b0d`) из палитры.
Это **визионерский выбор** — чёткая, нейтральная заглушка лучше ужасной артуры.

Когда ассеты будут добавлены (на этапе Content / UI & Assets), они должны
соответствовать design system из `~/Downloads/signal-arena-design-system.zip`.

## 2. Арт-ассеты (кандидаты на будущее)

Когда арт будет создан, он должен включать:

### Иконки (ярус A, условное)
- Иконки навигации (Arena, Academy, Collection, More)
- Иконки доменов (technical, risk, context, crypto, human, cognitive)
- Размер: 24×24 (stroke-семейство)

### Иллюстрации (яру� B, на карте)
- Враги: 33 × (стадии S1–S4 + аватар + иконка)
- Карты навыков: 17 + Cwait
- Размеры из таблицы ниже

| Элемент | Размер |
|---|---|
| Заглушка врага | 512×512 |
| Аватар врага | 400×400 |
| Иконка врага | 96×96 |
| Карта навыка | 220×320 (портрет) |
| Иконка меню/домена | 24×24 |
| Фон сцены | рисуется кодом, не арт-файл |
