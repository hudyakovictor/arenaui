# Signal Arena — первый вход игрока

Иллюстрированные рендеры **не прототипов** (не cyan-терминал, не HTML-wireframe), а в стиле референсов: Leverage Goblin / Wick Mimic в переулке / панк-таблоид.

Последовательность = то, что видит игрок с чистого `onboarding_done = false`, эпоха I «Улица», L1.

Открыть: `index.html`.

## Что сознательно не показали

Первый вход **не** содержит Бестиарий / Коллекцию / Маркет / Турниры — они появляются с эпохами (Часть 2, ось навигации). Энергия, F2P-таймеры, раскрытие ответа в заголовке, цвет кнопок «верно/опасно» — запрещены.

Карты — живописная метафора (свеча), не набор плоских иконок из «пример карт но иконки все не подходят».
