# Персоны AI-агентов

Определения ролей для AI-агентов, работающих над проектом. Каждый агент
специализируется на своей области и знает, какие технологии использовать и
какие — избегать.

## Список агентов

| Агент | Область | Технологии |
|---|---|---|
| `frontend.md` | Игровой клиент | Phaser 4, TypeScript, Vite, Zustand |
| `backend.md` | Сервер + CRM | Fastify, SQLite, Drizzle, Zod, WebSocket |
| `game-design.md` | Игровой дизайн | Механики, сцены, сущности, стиль текста |

## Как использовать

AI-агент выбирает персону, читает соответствующий файл и действует в рамках
этой специализации. Персоны не привязаны к конкретному AI-продукту — любой
агент может их использовать.
