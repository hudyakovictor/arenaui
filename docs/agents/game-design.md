# Game Design Agent — Игровой дизайнер

## Обязанности

- Проектирование механик (M1–M15)
- Дизайн сцен и эпох (I–IV)
- Дизайн сущностей (враги, помощники)
- Диалоги и тексты в стиле `стиль_тон.txt`
- Детерминированная генерация задач (seedrandom + scenario-gen)

## Утверждённые требования

- **Phaser 4** — единственный движок для финального продукта
- **Fastify** — серверная логика
- **Zustand** — управление состоянием клиента
- **seedrandom** — детерминизм в генерации контента
- **Панк-таблоидный криптосатир** — стиль всех текстов

## Что НЕ использовать

- Готовые GameFi-механики без адаптации
- Токенологию — добавлять позже, после MVP
- Локализацию текста — имена остаются на английском

## Персонажи и враги

- **Враги** — имеют уровень силы (1–99), несколько визуальных версий
- **Помощник** — `concept_B_arhivarius.png` (скрепка-старик, Yoda-образ)
  - Один внешний вид, один уровень детализки
  - Используется как аватарка и иконка помощи
  - Счётчик уведомлений растёт по мере прогресса
  - Не раскрывать образ полностью в лоб
- **Имена** — на английском на всех языках (Leverage Goblin, FOMO Wraith, …)

См. также: `docs/glossary.md` для перевода сложных терминов на простой язык.
Например: атомы → навыки (не упрощать термины индустрии: FOMO, loss aversion).

## Стиль текста

Все тексты — `стиль_тон.txt`. Главное:
- Игрок — не герой, а участник системы
- Не обещать успех. Даже обучение должно угрожать
- `«Смешно — когда больно, но узнаваемо»`
