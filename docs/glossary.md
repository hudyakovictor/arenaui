# Глоссарий — сложные термины простыми словами

> **Правило:** если термин сложный — используй простой вариант. Игрок на L0–20
> не должен ничего «расшифровывать». Если разработчик не понимает термин — игрок
> тем более не поймёт.

## Карта терминов

| Сложный термин | Простой вариант | Что это значит |
|---|---|---|
| **Атом** | **Микро-навык** | Минимальное умение из одной карты. Например, «прочитать свечу» или «FOMO». Карта состоит из 3–5 микро-навыков |
| **Свиток ошибок** | **Журнал ошибок** | Запись каждой ошибки игрока: что не понял, какой враг, какая улика пропущена |
| **Бюджет риска** | **Ограничение риска** | Счёт, который убывает при ошибках и пополняется при правильных ответах. Когда доходит до нуля — игра заканчивается |
| **Холодная голова** | **Пауза / Бездействие** | Когда игрок выбирает ждать вместо действия. Иногда это правильный ответ |
| **Тень арены** | **Фоновый эффект** | Визуальный слой за графиком, появляется с уровня 1 |
| **Мутация сценария** | **Случайные изменения** | Меняет детали задания (вопрос, источники, варианты ответов) — чтобы одна и та же ситуация не повторялась одинаково |
| **Калибровка** | **Оценка уверенности** | Система запоминает: насколько часто игрок ставит «высоко», а оказывается неправ |
| **Погода** | **Рыночный режим** | Состояние рынка: волатильный, плоский, тренд и т.д. Меняет поведение |
| **Вердикт конфликта** | **Выбор сигнала** | Когда два источника дают разные сигналы — выбираешь важный |
| **Опознание врага** | **Угадать врага** | После ответа — назови кто это был по внешности |
| **Проигрыш вперёд** | **Продолжение графика** | График продолжает рисоваться после твоего решения, чтобы увидеть исход |
| **Трофеи** | **Достижения врагов** | Когда побеждаешь врага — он сохраняется в коллекцию |
| **Комбо** | **Цепочка карт** | N правильных ответов подряд с двумя картами — открывает супер-способность |
| **Сессия** | **Раунд** | Одно задание = один раунд |
| **Разминка** | **Ежедневные задачи** | Короткая разминка из ранних уровней каждый день |
| **Мастер-рендер** | **Основной рисунок** | Главный арт одного размера, из него создают все форматы |
| **Карта навыка** | **Навык** | Обучающая карточка (17 штук, C1–C17) |
| **Источник** | **Вкладка данных** | График, новости, позиция, стакан и т.д. — только нужные для решения |
| **Стадия врага** | **Уровень врага** | S1–S4 — враг становится сильнее и сложнее |
| **Глава** | **Карта** | Раздел Академии (17 карт = 17 глав) |
| **Этап** | **Игрок осваивает** | 4 периода освоения: L0–20, L21–50, L51–80, L81–99. Костыли снимаются постепенно: подсветка → подсказка после ошибки → без подсказок → ложные подсказки |
| **Shop / Marketplace** | **Магазин** | Оставлять как есть — простой термин |

## Что НЕ упрощать

**Термины индустрии трейдинга** остаются как есть — они есть во всех обучающих
материалах и используются профессиональными аналитиками:

- FOMO, Loss Aversion, Slippage, Leverage, Stop-loss, Take-profit
- Support/Resistance, Volume, Liquidity, Market Structure
- News, On-chain, Orderbook, Sentiment, Tokenomics
- Risk Management, Position Size, Trailing Stop

## Почему «атом» плох

Даже с определением «минимальная проверяемая единица знания» — непонятно
**для чего это нужно** и **связь с игровым процессом**.

**Атом** = **навык внутри карты**. Пример: карта «Основы рынка» содержит навыки
«прочитать свечу», «отличить импульс от отката». Когда игрок сталкивается с врагом,
игра проверяет: **навыки каких карт нужны этому врагу**. Если навык не освоен —
враг сильнее, обратная связь менее полная.

**В UI:** используй «навык» или «умение». «Атом» — только в типах кода.

## Принцип

1. В коде (TypeScript) используй оригинальные термины (они в типах)
2. В UI и тексте игры — **термины индустрии оставлять**, проектные термины **упрощать**
3. В документации для AI — оба варианта: сначала простой, потом технический
4. **Атомы** → всегда пиши «навык» или «умение» в UI и описаниях
