# Матрица механик: взаимодействия и UI

> Статус аудита: 2026-09-06. Это матрица взаимодействий между механиками,
> описанными в `CONCEPT_IDEAS.md`. Устаревшие ссылки на файлы удалены.

## Как устроена прогрессия

Игрок растёт **по уровню** (L0→99). Этапы освороения — это **пороги уровня**,
которые раскрывают новые механики:

| Этап | Уровни | Что включает |
|-------|--------|-------------|
| Улица | L0–20 | улика, сценарная мутация, тень арены, бюджет, проигрыш вперёд |
| Кабинет | L21–50 | ставка уверенности, вердикт конфликта, журнал ошибок, опознание врага |
| Терминал | L51–80 | стек решений, комбо карт, слепой источник, холодная голова |
| Система | L81–99 | погода рынка |

**Пороги уровней:**
```
[0, 100, 250, 500, 1000, 1800, 3000, 4800, 7200, 10000, 15000,
 22000, 31000, 42000, 56000]
```
Уровень = индекс порога, когда XP превышает его значение.

**Дополнительные пороги по уровню:**
- level < 3 → confidence выключен
- level < 8 → identifyOptions = 0
- level < 14 → stackSlots = 0

## Последовательность появления (chronological)

Игроки видят механики в этом порядке по мере прогрессии:

```
L0–20:  улика, проигрыш вперёд, мутация, тень арены, бюджет
L21–50: +ставка уверенности, вердикт конфликта, журнал ошибок, опознание врага
L51–80: +стек решений, комбо карт, слепой источник, холодная голова
L81–99: +погода рынка
```

**Комбо** — это **сокрытая механика**: враги на S3/S4 этапах требуют определённые
комбо (`comboRequired: ['K01', 'T05' ...]`), но **логика обнаружения отсутствует**.
Комбо открывается при N верных ответах с нужными картами, но логика не реализована.

## Баги, найденные в ходе аудита

### Баг 1: Переход этапов никогда не срабатывает

**Суть:** при переходе уровня (20→21, 50→51, 80→81) анимация перехода этапа
не показывается, т.к. уровень уже обновлён до сравнения.

**Фикс:** запоминать предыдущий этап до `addXp`, либо сравнивать сохранённое
значение этапа с новым перед обновлением.

### Баг 2: Комбо — данные есть, логика нет

`scoreEncounter()` никогда не:
- не проверяет `enemy.comboRequired`
- не сравнивает выбранные карты с `combos[].cards`
- не ставит `comboProgress: true`
- не добавляет в `progress.combosUnlocked`

**Фикс:** в `ArenaScene.onSubmit` перед scoring добавить проверку комбо.

### Баг 3: Опознание врага — перемешивание не детерминировано по seed

`FeedbackOverlay` использует `shuffle` на основе `encounter.seed`, но
алгоритм сортировки `(seed + charCode) % 7` может давать одинаковые значения
для разных врагов, что приводит к нестабильному порядку в ES2020.
