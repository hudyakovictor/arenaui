# Команды для AI-агентов

Готовые инструкции для AI-агентов. Каждая команда — это конкретная задача с
пошаговыми действиями. AI-агент может вызвать команду, чтобы быстро выполнить
стандартную операцию без необходимости придумывать шаги самостоятельно.

## Список команд

| Команда | Что делает | Когда использовать |
|---|---|---|
| `dev-setup` | Настройка среды разработки | Первый запуск, новая машина |
| `dev-run` | Запуск dev-серверов | Разработка нового функционала |
| `test` | Запуск тестов | Перед коммитом, после изменений |
| `lint` | Проверка кода | Перед сдачей, после правок |
| `build` | Сборка production | Перед деплоем |

## Как использовать

AI-агент читает файл команды из `docs/commands/`, изучает пошаговую инструкцию,
выполняет шаги и сообщает результат. Никаких специальных плагинов не требуется.
